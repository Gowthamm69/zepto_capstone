# Zepto Capstone Project

## Overview

This repository contains the complete Capstone Project consisting of three modules that demonstrate data engineering, data analytics, and AI-powered customer support.

---

## Repository Structure

```
zepto_capstone/
│
├── module_1_data_pipeline/
├── module_2_analytics/
├── module_3_support_assistant/
└── README.md
```

---

## Module 1 – Data Pipeline

### Description

Built an end-to-end data pipeline for processing the Titanic dataset.

### Features

- Data loading
- Data cleaning
- Feature engineering
- Pipeline automation
- Documentation

---

## Module 2 – Analytics

### Description

Performed exploratory data analysis and machine learning on the Titanic dataset.

### Features

- Data preprocessing
- Exploratory Data Analysis
- Classification models
- Regression model
- SMOTE
- GridSearchCV
- Model comparison
- Model serialization using Joblib

---

## Module 3 – AI Support Assistant

### Description

Developed an AI-powered customer support assistant using Retrieval-Augmented Generation (RAG).

### Technologies

- FastAPI
- LangGraph
- ChromaDB
- Sentence Transformers
- Groq LLM
- Docker

### Features

- Semantic search
- Intent classification
- Document retrieval
- Context-aware response generation
- REST API
